# podori-egov · 전자정부 보안

한국어 안내 | [English](README.en.md)

**정부 보안 기준을 코드와 검증 근거로 연결합니다.**

전자정부프레임워크 프로젝트의 보안 검토·수정·회귀 검증을 위한 독립 스킬입니다. 정부 보안약점 항목마다 무엇을 확인하고 어떤 근거를 남겨야 하는지 안내합니다. 버전별 규칙과 코드 사례도 함께 제공합니다.

## 같은 호출, 같은 기준

슬래시 호출을 지원하는 에이전트에서는 대상 프로젝트에서 다음과 같이 호출합니다.

```text
/podori-egov
```

다른 podori 스킬과 마찬가지로, 연결망과 폐쇄망에서 동봉한 기준과 승인된 로컬 자료로 검토합니다. 필요한 수정과 검증까지 수행하는 것이 기본입니다. 검토만 요청하면 코드를 바꾸지 않습니다. 다른 podori 스킬이나 MCP는 필요하지 않습니다.

## 동봉한 기준

| 자료 | 범위 |
|---|---|
| 행정안전부고시 제2025-1호 별표 3 | 설계 20개·구현 49개 항목의 적용 조건, 점검 방법, 검증 기준 |
| 소프트웨어 개발보안 가이드 2021.11 | 항목별 장·절·쪽 번호와 출처 판본 |
| eGovFrame 3.x·4.x·5.x 규칙 | 실제 버전·설정에 따른 추가 점검과 로컬 코드 사례 |
| 보고서·항목별 점검표 | 근거, 미확인 항목, 필수 검증, 작업 종료 조건 |

출처 판본과 원문 파일 해시는 [출처 기록](references/source-baseline.json)에 있습니다. 항목별 영어 지침은 [정부 기준 안내](references/government-baseline.md)에서 확인할 수 있습니다. 출처 링크와 원문 PDF는 검토 실행에 필요한 입력이 아닙니다.

## 폐쇄망으로 가져가기

1. `podori-egov` 폴더 전체를 승인된 방식으로 옮기고 파일 목록과 무결성을 확인합니다. `SKILL.md`만 복사하면 참조 자료가 빠집니다.
2. 내부망에서 동작하는 에이전트·모델과 대상 소스, 필요한 로컬 도구·의존성을 준비합니다. 스킬이 이를 설치하거나 내려받지는 않습니다.
3. 대상 프로젝트에서 스킬을 호출합니다. 에이전트별 설치 위치와 호출 문법은 해당 환경의 안내를 따릅니다.

실행 절차와 도구·자료가 없을 때의 처리는 [오프라인 실행 지침](references/offline-execution.md)에 있습니다. 기본 검토 중에는 공식 자료, CVE 데이터, 의존성을 자동으로 갱신하지 않습니다. 갱신은 승인된 별도 작업으로 수행합니다.

## 결과 읽기

- 각 항목에 적용 근거, 확인한 제어, 실제 검증 결과 또는 미확인 이유를 남깁니다.
- 필수 테스트를 실행하지 못하거나 필요한 CVE 자료가 없으면 해당 판단을 미검증으로 남깁니다. 가능한 로컬 점검은 계속하되, 필수 검증이 막히면 확인한 결과와 중단 이유를 반환합니다.
- 보고서에서 정한 필수 수정과 검증을 마치면 종료합니다. 별개의 새 문제는 후속 목록으로 분리합니다.

같은 스킬·소스·근거·승인·도구 조건에서 같은 절차와 판정 기준을 사용합니다. 모델의 문장이나 탐지 결과가 항상 같다는 뜻은 아닙니다. 내부망 모델과 실제 격리 환경은 별도로 필요합니다.

이 스킬은 공식 인증이나 법적 준수 판정을 대신하지 않습니다. 동봉한 사례의 테스트도 실제 프로젝트 검증을 대신하지 않습니다.
