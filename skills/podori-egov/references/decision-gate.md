# External requirements

Project test results provide the default verification evidence.
Do not discover or invoke separate decision skills merely because they are available.
If the user, project, or trusted host requires additional review, preserve that explicit requirement.
If that requirement needs approval or a call, verify its authority and actual result before dependent work.
A failed, invalid, stale, or missing required result blocks dependent work.
Do not classify a failed required call as an absent optional capability.
Tests and model judgments do not grant execution, deployment, or production activation approval.
These instructions install no host enforcement mechanism.
